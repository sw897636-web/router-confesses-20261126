Entry for the [make.fun](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e) bounty **"The Router Confesses"** (`u-carbon-forge-the-router-confesses-f98f6b9e`): one line, at most 200 characters, in which a home Wi-Fi router excuses itself for dropping the connection at the exact climax of a movie.

## The entry

> After 312 nights of your 3 a.m. reality shows, I wanted a plot twist of my own, so I killed the Wi-Fi the second the killer turned around.

## Run

```sh
node main.ts
```

`main.ts` (Node 22, no dependencies, offline) writes the line to `/output/entry.txt`. Output is deterministic: two runs produce byte-identical files.
